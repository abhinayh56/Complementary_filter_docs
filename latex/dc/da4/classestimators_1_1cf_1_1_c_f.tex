class estimators::\+cf::\+\+CF$<$ T $>$}
Generic complementary filter for sensor fusion. 

The \doxylink{classestimators_1_1cf_1_1_c_f}{CF} class implements a first-\/order complementary filter that combines two input measurements into a single filtered output.

The filter can be configured using either the cutoff frequency and sampling time or directly using the filter parameters.

The class is templated so that the filter can operate on different numeric types such as {\ttfamily float} or {\ttfamily double}.
